# 科目A模試1 全60問・図解解説

提供された「FE科目A模試①」の問題画像と「FE科目A模試解説①.pdf」を使用した、基本情報技術者試験 科目Aの学習サイトです。

## 主な機能

- 全60問の試験演習と採点
- 問題別の解説手順、専用図、PDF準拠の詳しい説明
- 重要用語カード
- 確認できた原資料と関連問題群を分けた出典分析
- 端末内への回答・復習状況の保存

## 公開用ファイル

この `public` フォルダーには、問題画像、問題・解説データ、画面表示用のHTML・CSS・JavaScriptが入っています。サイト全体をビルドした公開用成果物は、プロジェクト直下の `build` フォルダーに生成されます。

## 原資料

- 問題本文：提供された「FE科目A模試①」の問題画像
- 正答・解説：提供された「FE科目A模試解説①.pdf」

原資料に年度・試験区分・問番号が記載されていない設問は、原典未特定として扱います。公開問題サイトは転載元として断定せず、復習用の関連問題群として案内します。
